# Phase 0

The plan, with every spike, its pass criteria and what it needs, is the living document
"POS Phase 0 Plan": https://claude.ai/artifact/3GRXr5TH4Cn7MeHbKwKatn

Each spike has a folder under `spikes/` with its question, how it is run, and its result once known.

Phase 0 is done when two tablets and a laptop hub take orders, print a kitchen ticket, and merge correctly
after being disconnected; the menu engine prices the worked example; a Stripe reader takes a sale, a
pre-authorized tab and an offline sale from the POS; partner terms are confirmed in writing; and PIN, NFC
and face sign-in work on each station type.
